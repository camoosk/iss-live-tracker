# ISS Live Tracker

Real-time 3D visualization of the International Space Station orbiting Earth, with live orbital data and a bilingual Indonesian/English interface.

## Project Goals

- Real-time ISS position tracking
- Interactive 3D Earth visualization
- Orbital telemetry and location information
- Indonesian and English language support
- Responsive web experience
- GitHub Pages deployment

## Languages

- 🇮🇩 Bahasa Indonesia
- 🇬🇧 English
